# Architecture and decisions

- **.NET 10 / WPF**, self-contained win-x64. Core contracts, inference, validation, duplicate receipts and bridge are platform-independent.
- **Existing browser extension** records clicks, changed inputs, copy/paste and bounded page snapshots. Recording is explicit. Selectors prefer IDs/names. Capturing inaccessible frames/shadow roots and arbitrary rich editors is outside this preview.
- **Kestrel loopback bridge**, `127.0.0.1:47653`, works without an administrator HTTP.sys URL reservation. 96-bit one-time pairing code, rotating 256-bit session token, paired extension-origin checks, no wildcard CORS, 100 KB request bound. Not a defence against malware already running as the same local user.
- **Local inference**, pinned official Google Gemma 4 E2B QAT Q4_0 (3,349,516,256 bytes), llama.cpp b11852 CPU x64. Downloads have upstream SHA-256 metadata; model revision and release URL are immutable in the shipped manifest. Text-only, no multimodal projector. No cloud inference calls. Runtime binds loopback on 47654 with a process-specific API key.
- **Budgets:** 8,192 context tokens, single slot, max 1,800 output tokens, thinking disabled, temperature 0.1; browser evidence up to 16,000 characters with both ends of a long recording preserved. Characters are not tokens; pathological input may still overflow and should fail, not silently truncate output. CPU threads capped at six. Weight size is not total RAM; runtime buffers and KV cache add memory. 128K advertised context is deliberately unused. Windows laptop benchmarks remain necessary.
- **Separate AI stages:** discovery into constrained workflow JSON, extraction from a new page, optional semantic trigger matching. Descriptions must describe extraction, not memorise examples. Questions block approval. JSON parsing/semantic validation fail closed. A single demo cannot prove every inferred constant or variable: review is essential.
- **Execution:** fixed navigate/fill/click/appendRow primitives, no generated arbitrary JavaScript or C# from model output. DOM fill verifies the value, click waits for a visible success locator; Sheets re-exports CSV. Persisted pending receipts are written before execution, preventing automatic repeat after crash/unknown result. This gives conservative retry protection, not transactional exactly-once semantics. CSV dedup also checks whole-row equality. Concurrent external spreadsheet editors are not coordinated: avoid concurrent writes.
- **Playwright decision:** Playwright recording works best in its own browser context; attaching to ordinary already-running Chrome requires remote debugging and may involve a separate user-data directory. The user's existing authenticated session is essential, so production execution uses extension DOM actions and `chrome.debugger` trusted keyboard input for Sheets. Playwright drives integration tests against the same browser primitives and actual extension. This is a deliberate exception to the initial Playwright preference.
- **Packaging:** GitHub Actions Windows build, test, UI smoke, self-contained ZIP and per-user Inno installer. No Windows service, global hooks, separate browser profile or authentication-cookie copying. Signing and browser-store publishing are future distribution steps.

## Scope limits

Google Sheets adapter relies on current name-box selectors, clipboard permission and CSV export. It must be validated on a real account. Empty/complex sheets, formulas, filtered or sorted ranges and simultaneous editing need care. No generic repair agent: failures identify the missing target; edit and reapprove the workflow. Read-back is stronger than a click count but a visible success locator can still be chosen poorly. Models do not get permission to create new steps at execution time.

Runtime response grammar is JSON-object constrained, followed by typed deserialization and validation; a full per-workflow JSON schema grammar and a friendlier clarification editor would improve reliability. Sensitive fields are omitted, but non-field page text is not a general-purpose PII detector.
